Full stability audit (2026-09-17)

Audited source areas: app/, lib/, server/, hooks/, components/, shared/, constants/ plus package/build config.

Stability fixes applied:
1. DG SSE table snapshots now reuse unchanged table object references instead of rebuilding every card on every packet.
2. Heavy dashboard/table/video tree is not rendered behind the full-screen MT/DG game iframe; floating assistant/radar/calculators remain mounted.
3. Dealer FLV retry is single-flight: repeated mpegts/video errors can no longer stack many retry timers/players.
4. Tracker sessions now carry lastSeen and stale sessions expire after 15 minutes without heartbeat.
5. Server sweeps inactive DG relays every minute, stopping orphan Chromium processes when a tab/device disappears without logout.
6. /api/health exposes DG relay count for Render diagnostics.

Not changed:
- MT WebSocket protocol, authentication, road calculation, settlement/today-PnL logic.
- Baccarat road rules.
- User-visible layout and game controls.
- No Wake Lock, visibility auto-reload, root DOM display rewrite, or idle-screen recovery logic was added.
