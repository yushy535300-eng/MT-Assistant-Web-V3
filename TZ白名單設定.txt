MT MATRIX｜TZ 白名單設定

1. 部署這個版本到 Render。
2. Render → 你的 Web Service → Environment 新增：
   ADMIN_PASSWORD = 你自己的管理員密碼
   TZ_WHITELIST_ENABLED = false
   DATABASE_URL = 你目前專案使用的 MySQL DATABASE_URL
3. Deploy 完成後開：
   https://你的程式網址/admin
4. 用 ADMIN_PASSWORD 登入，先新增自己的 TZ 帳號。
5. 確認後台能看到自己的帳號後，把 Render：
   TZ_WHITELIST_ENABLED = true
6. 重新 Deploy。

之後：
- 白名單內 + 未到期 + 未超過裝置上限 → 可以登入 MT Assistant
- 不在白名單 → 顯示「此 TZ 帳號尚未取得 MT MATRIX 使用授權」
- 到期 → 顯示授權已到期
- 停用 → 無法登入
- 超過裝置上限 → 無法登入

後台功能：
- 7 / 30 / 90 天 / 永久
- 裝置上限 1～3 台
- +30 天
- 啟用 / 停用
- 解除裝置綁定
- 刪除授權

注意：
第一次部署先不要直接把 TZ_WHITELIST_ENABLED 設 true，先把自己的 TZ 帳號加入，避免自己被擋在外面。
